For help with Termight, write to [termight.app@gmail.com](mailto:termight.app@gmail.com). Say what you were doing, what you expected and what happened instead.

## What you need

- An iPhone with iOS 26 or later.
- A GitHub account that can use GitHub Codespaces.
- To run coding agents: an account or API key with an AI provider.

## Common questions

**What does it cost?**
Termight is free. GitHub bills codespace usage to your GitHub account; personal accounts include a free monthly allowance. AI providers bill their own usage.

**Why did my codespace stop?**
GitHub stops a codespace after a period without activity, 30 minutes by default. Termight shows "Stopped" and a Start button. Nothing is lost; start it again and continue.

**Does Termight start codespaces on its own?**
No. A codespace starts only when you tap Start, or open or resume an agent session.

**How do I sign in with an access token?**
On the sign-in screen, tap "Use an access token". Create a classic token on GitHub under Settings → Developer settings → Personal access tokens, with the `codespace`, `repo` and `read:user` scopes.

**Where are my API keys kept?**
As GitHub Codespaces secrets in your own GitHub account. They are not stored on your phone. A new key reaches a codespace the next time it starts.

**How do I remove Termight's access to my GitHub account?**
Sign out in the app's Settings, then revoke the app at [github.com/settings/applications](https://github.com/settings/applications).
